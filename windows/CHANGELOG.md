# 更新日志

## v1.3.0

- 新增粘贴文本分析，无需框选；明确前缀区分双方，最多 20,000 字符，分析最后 10 条消息，完整输入仍进行交易内容检查。
- 新增取消分析与分阶段重试，保留已完成结果，排序失败可复制未排序候选；旧请求结果不会覆盖新任务。
- 新增回复长度、风格及六语言偏好，支持保存全局默认和仅本次覆盖；旧设置保持简短、自然、中文。
- 分析使用冻结的任务配置，截图与框选串行恢复，分析与更新下载互斥；聊天及任务缓存仅保留在内存。

## v1.2.1

- 新增 11 个模型供应商预设：DeepSeek、通义千问、Kimi、智谱 GLM、豆包、硅基流动、OpenAI、Anthropic、Gemini、OpenRouter 和 Ollama；自动填写接口地址、协议与推荐模型。
- 新安装自动初始化模型预设，已有配置及主动清空的模型列表保持原样；模型列表读取失败时保留推荐项，也可手动填写模型名称。
- 支持 Ollama 等本地回环服务免 API Key 测试连接与生成回复；读取模型列表时仅向匹配的已保存地址和协议复用密钥，避免跨服务泄露。
- 新增 한국어（韩文／朝鲜语）界面，覆盖设置、进度、错误、更新提示与分析结果标签；支持即时保存切换及韩文系统语言识别。
- 统一使用桌面框选与本地 OCR，移除旧微信窗口探测和 UI Automation 路径及依赖；旧版客户端相对坐标会清空，需重新框选。
- 启动时检查前端构建产物是否过期，源码、翻译或构建配置更新后自动重建，避免显示旧界面。
- CI 增加构建产物新鲜度检查与浏览器冒烟测试，补充供应商、密钥隔离、旧配置迁移、OCR 样本及六语言回归覆盖。

## v1.2.0

- 新增应用内自动更新：启动后静默检查 GitHub Releases，发现新版本时主页显示提示横幅。
- 设置页新增"版本与更新"区块，可手动检查更新、应用内下载（带进度与取消）、SHA256 校验后一键"重启并安装更新"。
- 更新采用"退出主程序 + 独立辅助程序换目录 + 自动重启"三段式，替换失败自动回滚到旧版本。
- 更新检查仅向 GitHub 查询版本信息，不发送任何聊天内容；翻译资源、下载与校验全部本地完成。
- 分发包新增 update_helper.exe（更新辅助程序，需与主程序同目录）。
- 修复设置页更新进度不刷新、以及更新重启在桥接调用中强制退出进程的问题。
- 强化交易内容拦截：识别 OCR 造成的字符分隔（如"转 账"）并扩充敏感词表，避免漏判。
- 排查并修复语言切换后部分提示与错误信息未跟随翻译的问题。
- 内部重构：拆分原桥接类，分析流程、界面语言状态、框选与更新各自独立，便于后续维护。

## v1.1.1

- 增加英语、法语、俄语、日语界面，保留简体中文；覆盖设置、提示、确认框、分析结果标签、桌面标题与框选提示。
- 界面语言独立即时保存和切换；新用户跟随 Windows 语言，旧用户升级保持简体中文。
- 进度和错误采用可翻译的结构化消息，切换语言后已有提示与后续分析进度同步更新。
- 调整长文本换行和系统字体回退，翻译资源随 Windows 分发包内置。
- 本次仅本地化界面，OCR、聊天原文、用户配置内容与中文候选回复生成逻辑保持现状。

## v1.1.0

- 优化分析与 OCR 阶段的窗口响应，降低界面卡顿。
- 多显示器支持：框选层兼容负坐标副屏，启用按显示器 DPI 感知，适配混合分辨率/缩放设备。
- 修复配置模型弹窗点击空白处误关闭的问题，模型选择改为与应用风格一致的自绘下拉。
- 接口地址填到 `/v1` 层级即可自动补全协议对应端点，切换协议自动更新路径。
- 模型列表拉取兼容公开端点与需鉴权端点（401 时自动携带用户 API Key 重试）；错误提示不再显示内部类名。
- 修复框选入口的界面桥接死锁（启动框选不再导致窗口未响应）。

## v1.0.0

- 支持 Windows 电脑版微信 `Weixin.exe` / `WeChat.exe`。
- UI Automation 优先，本地 RapidOCR 兜底读取用户框选的可见聊天区。
- 直连 TypeSafe Jev API，展示真实意图、危险程度、对方需求、最佳动作等结构化判断。
- 可选直连 DeepSeek API，依据 Jev 判断生成三条建议回复。
- Jev 与 DeepSeek 密钥分别保存在 Windows 凭据管理器，不写入普通配置文件。
- 建议回复只能复制，不自动填写或发送微信消息。
- 截图时自动隐藏助手窗口，避免递归 OCR。
- 会话白名单、交易敏感词拦截和清晰的分阶段状态提示。
