# Jev 대화 도우미 (Windows PC)

[简体中文](../README.md) | [English](README.en.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

**버전: v1.3.0**

이 프로젝트는 오픈 소스 프로젝트 [332_lab-jev-chat](https://github.com/Liyucheng1997/332_lab-jev-chat)의 판단 질문 모음과 분석 흐름을 바탕으로 Windows PC용으로 재개발한 프로그램입니다.

Windows 버전에서는 바탕 화면의 대화 영역을 선택하면 로컬 OCR로 화면에 보이는 텍스트를 인식하고, Jev를 통해 대화를 분석합니다. 답변 모델을 설정하면 답변 후보 세 개를 생성하고 Jev가 이를 평가합니다. 답변 후보는 확인하거나 복사할 수 있으며, 대화 입력창에 자동으로 입력하거나 전송하지 않습니다.

[Windows용 v1.3.0 다운로드](https://github.com/QCJLchina/Jev-chat-assistant/releases/tag/v1.3.0) · [전체 변경 내역 (중국어)](../windows/CHANGELOG.md)

## v1.3.0의 새로운 기능

- **대화 텍스트 붙여넣기**: 화면 영역을 선택하지 않고도 분석할 수 있습니다. `我：` / `对方：` 또는 `me:` / `other:` 접두사를 지원하며, 영문 접두사는 대소문자를 구분하지 않습니다. 반각·전각 콜론을 모두 사용할 수 있습니다. 입력은 최대 20,000자이며 마지막 10개 메시지를 분석합니다. 거래 관련 내용에 대한 안전 검사는 입력 전체에 적용됩니다.
- **취소 및 단계별 재시도**: 완료된 판단과 답변 후보를 유지하고 미완료 단계부터 다시 실행합니다. 후보 평가에 실패해도 답변을 복사할 수 있습니다. 재시도는 작업 시작 당시의 관계 설명, 모델 및 답변 설정을 사용합니다. 변경한 설정을 적용하려면 새 분석을 시작하세요. 취소하면 이후 단계가 중단되고 이전 작업의 결과는 무시되지만, 이미 전송된 HTTP 요청은 응답 또는 시간 초과까지 계속 진행될 수 있습니다.
- **답변 설정**: 답변 길이(간단하게 / 자세하게), 말투(자연스럽게 / 격식 있게 / 부드럽게 / 직접적으로), 답변 언어의 기본값을 저장할 수 있습니다. 홈 화면에서는 기본값을 바꾸지 않고 현재 세션에만 적용되는 설정을 사용할 수 있습니다. 답변 언어는 화면 표시 언어와 별도로 지정하며, 중국어 간체·영어·프랑스어·러시아어·일본어·한국어 또는 화면 표시 언어에 맞추기를 지원합니다.
- **작업별 결과 관리**: 새 작업을 시작하면 이전 요청의 결과가 새 분석을 덮어쓰지 않습니다. 대화 텍스트와 단계별 결과는 메모리에만 유지되며 로컬 대화 기록으로 저장하지 않습니다.

## 시스템 요구 사항

- Windows 10/11 (x64)
- Microsoft Edge WebView2 Runtime
- 소스에서 실행하거나 빌드할 경우 Python 3.12, Node.js 20 이상 및 npm
- 처음 사용할 때 TypeSafe / Jev API Key 필요. 답변 모델의 API Key는 선택 사항이며, 로컬 모델 서비스는 키 없이 사용할 수 있습니다.

## 설치 및 실행

저장소의 최상위 폴더에서 PowerShell을 열고 실행하세요.

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1
powershell -ExecutionPolicy Bypass -File .\windows\start.ps1
```

처음 실행하면 설정 화면에서 Jev API Key를 입력하고 저장하세요. 답변 후보를 생성하려면 사용할 답변 모델의 연결 주소, 모델 이름 및 필요한 API Key도 설정하세요. 배포용 프로그램은 다운로드한 ZIP 파일의 압축을 푼 뒤 `Jev对话助手.exe`를 실행하면 됩니다.

## 화면 표시 언어

중국어 간체, 영어, 프랑스어, 러시아어, 일본어, 한국어를 지원합니다. 설정에서 **인터페이스 언어**를 선택하면 즉시 저장되고 적용됩니다. 재시작할 필요가 없으며, 다른 미저장 설정은 함께 저장되지 않습니다.

새 사용자는 기본적으로 Windows의 표시 언어를 따릅니다. 한국어 Windows에서는 한국어가 선택되며, 지원하지 않는 시스템 언어는 영어로 표시됩니다. 언어 설정이 없던 이전 버전 사용자는 업그레이드 후에도 중국어 간체를 유지합니다.

표시 언어는 화면, 안내, 오류 메시지 및 분석 결과의 항목 이름에 적용됩니다. 대화 원문과 사용자가 입력한 관계 설명은 자동 번역하지 않습니다. 답변 언어는 별도의 답변 설정을 따릅니다. **한국어 화면과 답변을 지원하지만, 이번 업데이트에서 OCR의 인식 언어를 추가한 것은 아닙니다.**

## 사용 방법

### 화면의 대화 분석

1. 분석할 일반 텍스트 대화 창을 엽니다.
2. 홈 화면에서 **채팅 영역 선택** 버튼을 누르고 메시지 범위를 드래그합니다.
3. **선택한 영역 분석** 버튼을 눌러 Jev 판단과 답변 후보를 확인합니다.
4. 적절한 답변을 검토하고 복사한 뒤, 전송 여부는 직접 결정하세요.

### 붙여넣은 대화 분석

홈 화면에서 텍스트 붙여넣기 입력 방식을 선택하고 대화를 입력한 뒤 분석하세요. 발신자는 프로그램이 인식하는 접두사로 구분합니다. `나:` / `상대:` 같은 한국어 접두사는 지원하지 않으므로 다음과 같이 `me:` / `other:`를 사용하세요.

```text
me: 내일 몇 시에 만날까요?
other: 오후 두 시는 어때요?
me: 좋아요. 그때 만나요.
```

접두사가 없는 줄은 직전 메시지에 이어 붙입니다. 첫 줄에 접두사가 없으면 상대방의 메시지로 처리하며, 빈 줄은 무시합니다. 발신자를 번갈아 지정하거나 이름을 보고 자동으로 추정하지 않습니다. 입력이 20,000자를 넘으면 줄여야 하며, 초과 내용을 자동으로 잘라내지 않습니다.

프로그램은 대화 데이터베이스를 읽거나 대화 입력창을 조작하지 않으며, 메시지를 자동 전송하지 않습니다. 송금, 중국식 금전 선물인 홍바오, 수금·결제 등 기존 거래 관련 키워드가 감지되면 분석을 차단합니다. 한국어 거래 표현을 모두 감지하는 기능은 제공하지 않습니다. 이미지, 음성 메시지 및 인용 카드의 내용을 정확하게 복원하는 기능은 제공하지 않습니다.

## 빌드

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\build.ps1
```

빌드 결과는 `dist\Jev对话助手\Jev对话助手.exe`에 생성됩니다. PyInstaller가 Vue 정적 파일, OCR 모델 및 Python 실행 의존성을 함께 패키징하며, 업데이트 도우미 `update_helper.exe`도 생성합니다. 배포할 때는 주 실행 파일, `_internal` 폴더 및 업데이트 도우미를 같은 위치에 유지하세요. 대상 PC에도 Microsoft Edge WebView2 Runtime이 필요합니다.

프런트엔드를 이미 빌드했다면 `-SkipFrontendBuild` 옵션으로 `windows/frontend/dist`의 결과를 재사용할 수 있습니다.

## 앱 내 업데이트

프로그램은 실행 후 GitHub Releases에서 새 버전을 조용히 확인합니다. 새 버전이 있으면 홈 화면에 안내가 표시되며, 설정의 버전 및 업데이트 항목에서도 직접 확인할 수 있습니다. 업데이트 확인에는 대화 내용이 전송되지 않습니다.

업데이트를 시작하면 배포 ZIP 파일을 다운로드하고, 진행 상황을 표시하며 취소할 수 있습니다. 릴리스에 `SHA256SUMS.txt`가 있으면 SHA256을 검증하고, 없으면 파일 크기를 검사합니다. 재시작하여 업데이트를 설치하면 주 프로그램이 종료되고 `update_helper.exe`가 설치 폴더를 교체한 뒤 새 버전을 실행합니다. 교체에 실패하면 이전 버전으로 되돌립니다. `%APPDATA%`에 저장된 설정은 유지됩니다.

## 개인정보 및 데이터 처리

- OCR은 PC에서 실행됩니다. 분석 버튼을 누르면 인식된 텍스트 또는 붙여넣은 대화 텍스트가 TypeSafe Jev로 전송됩니다.
- 답변 모델을 사용하면 대화 텍스트와 Jev 판단이 선택한 모델 서비스에도 전송됩니다.
- API Key는 Windows 자격 증명 관리자에 저장합니다. `%APPDATA%\JevChatAssistant\settings.json`에는 비밀 정보가 아닌 설정만 저장합니다.
- 모델 목록 조회와 연결 테스트에는 대화 내용이 전송되지 않습니다.
- 업데이트 확인은 GitHub의 버전 정보만 조회하며 대화 내용은 전송하지 않습니다.
- 대화와 단계별 결과는 로컬 대화 기록 파일로 저장하지 않습니다. 기본 답변 설정은 저장하지만 홈 화면의 임시 답변 설정은 저장하지 않습니다.

자세한 설정과 제한 사항은 [Windows 사용 설명서 (중국어)](../windows/README.md)를 참고하세요.
