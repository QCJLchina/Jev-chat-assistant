# Помощник диалогов Jev (Windows PC)

[简体中文](../README.md) | [English](README.en.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

**Версия: v1.3.0**

Проект представляет собой переработку для Windows PC на основе банка оценочных вопросов и процесса анализа открытого проекта https://github.com/Liyucheng1997/332_lab-jev-chat.

Версия для Windows позволяет выделить область чата на рабочем столе, распознать видимый текст с помощью локального OCR, а затем проанализировать диалог через Jev. Также можно настроить модель ответов, которая создаст три варианта ответа, после чего Jev их ранжирует. Варианты ответов предназначены только для просмотра и копирования — они никогда не вставляются и не отправляются автоматически.

[Скачать v1.3.0 для Windows](https://github.com/QCJLchina/Jev-chat-assistant/releases/tag/v1.3.0)

## Новое в v1.3.0

- **Вставка текста диалога**: выделять область экрана не требуется. Поддерживаются префиксы `我：` / `对方：` и `me:` / `other:`; английские префиксы не зависят от регистра, допустимы обычное и полноширинное двоеточия. Лимит ввода — 20 000 символов; анализируются последние 10 сообщений, а проверки безопасности платёжного контента охватывают весь введённый текст.
- **Отмена и повтор с контрольных точек**: завершённые оценки и варианты ответов сохраняются, продолжение начинается с первого незавершённого этапа. При сбое ранжирования варианты по-прежнему можно копировать. Повтор использует зафиксированную конфигурацию исходной задачи, включая описание отношений, модель и предпочтения ответов. Чтобы применить изменённые настройки, запустите новый анализ. Отмена останавливает последующие этапы и игнорирует устаревшие результаты, но активный HTTP-запрос может завершиться или ожидать до тайм-аута.
- **Предпочтения ответов**: сохраняйте общие настройки длины, тона и языка, временно переопределяя их для текущего сеанса на главной странице. Язык ответов задаётся отдельно от языка интерфейса: упрощённый китайский, английский, французский, русский, японский и корейский либо следование языку интерфейса. Текст диалога и результаты этапов остаются в памяти; локальная история переписки не сохраняется.

## Требования

- Windows 10/11 (x64)
- Microsoft Edge WebView2 Runtime
- Python 3.12, Node.js 20+ и npm для запуска из исходников или сборки
- Ключ API TypeSafe / Jev при первом использовании; ключ модели ответов необязателен

## Установка и запуск

Откройте PowerShell в корне репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1
powershell -ExecutionPolicy Bypass -File .\windows\start.ps1
```

При первом использовании введите ключ API Jev на странице настроек. Для генерации вариантов ответов дополнительно добавьте конфигурацию модели ответов, её ключ API и название модели.

## Языки интерфейса

Поддерживаются упрощённый китайский, английский, французский, русский, японский и корейский. Выберите «Язык интерфейса» на странице настроек — он сохраняется и применяется сразу, без перезапуска и без отправки других несохранённых настроек. Новые пользователи по умолчанию получают язык интерфейса Windows (с откатом на английский для неподдерживаемых языков системы); существующие пользователи после обновления сохраняют упрощённый китайский.

Локализация охватывает интерфейс, сообщения и подписи результатов анализа. Текст переписки и введённые пользователем описания отношений не переводятся; OCR не изменился. Варианты ответов используют отдельную настройку языка: упрощённый китайский, английский, французский, русский, японский или корейский либо язык интерфейса.

## Использование

1. Откройте окно чата, в котором нужна помощь, и перейдите в обычный текстовый чат.
2. Нажмите «Выбрать область диалога» и выделите сообщения чата.
3. Нажмите «Анализировать текущее выделение», чтобы увидеть оценку Jev и варианты ответов.
4. Проверьте и скопируйте подходящий вариант, затем сами решите, отправлять ли его.

Программа никогда не читает базы данных чатов, не трогает поля ввода и не отправляет сообщения автоматически. Переводы, красные конверты и другой платёжный контент блокируются проверками безопасности. Изображения, голосовые сообщения и цитируемые карточки пока не восстанавливаются достоверно.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\build.ps1
```

Результат сборки: `dist\Jev对话助手\Jev对话助手.exe`. PyInstaller упаковывает ресурсы Vue, модели OCR и среду выполнения Python, а также создаёт вспомогательную программу обновления `update_helper.exe` (распространяйте рядом с основным exe). При распространении сохраняйте соседнюю папку `_internal`; на целевом компьютере также должен быть установлен Microsoft Edge WebView2 Runtime.

## Обновления внутри приложения

Приложение умеет самостоятельно загружать обновления. Через несколько секунд после запуска оно тихо проверяет GitHub Releases; при наличии новой версии вверху главной страницы появляется баннер, также можно проверить вручную в разделе «Версия и обновления» настроек. Проверка лишь запрашивает номер последней версии у `api.github.com` — содержимое переписки не передаётся.

После подтверждения приложение загружает архив выпуска в фоне (с индикатором прогресса и возможностью отмены), проверяет SHA256 (включено, если к выпуску приложен `SHA256SUMS.txt`; иначе используется проверка размера) и распаковывает во временную папку. После нажатия «Перезапустить и установить» основная программа завершается, помощник `update_helper.exe` атомарно заменяет каталог установки и запускает новую версию. При сбое выполняется откат к старой версии. Настройки и данные хранятся в `%APPDATA%` и не затрагиваются обновлением.

## Конфиденциальность

- OCR выполняется локально; после запуска анализа распознанный текст переписки отправляется в TypeSafe Jev.
- При включённой модели ответов текст диалога и оценка Jev отправляются в выбранный сервис для генерации вариантов ответов.
- Ключи API хранятся в диспетчере учётных данных Windows; `%APPDATA%\JevChatAssistant\settings.json` содержит только несекретные настройки.
- Список моделей и тесты соединения никогда не отправляют содержимое переписки.

О конфигурации, подробностях использования и ограничениях см. [`windows/README.md`](../windows/README.md).
