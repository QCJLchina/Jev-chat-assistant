# Jev チャットアシスタント（Windows PC 版）

[简体中文](../README.md) | [English](README.en.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

**バージョン: v1.3.1**

本プロジェクトは、オープンソースプロジェクト https://github.com/Liyucheng1997/332_lab-jev-chat の判定問題バンクと分析フローを基にした Windows PC 向けの再開発です。

Windows 版では、デスクトップ上のチャット領域を範囲選択し、ローカル OCR で表示中のテキストを認識して、Jev による会話分析を行えます。また、返信モデルを設定して 3 つの候補返信を生成し、Jev でランク付けすることもできます。候補返信は閲覧とコピーのみを目的としており、自動で入力や送信が行われることはありません。

[Windows 版 v1.3.1 をダウンロード](https://github.com/QCJLchina/Jev-chat-assistant/releases/tag/v1.3.1)

## v1.3.1 の新機能

- **会話全体のコンテキスト**：既定では全メッセージを分析し、最後の 10／20／50 件も選択できます。過去の会話を現在のメッセージの前に追加してから範囲を選択します。選択したメッセージ本文と背景説明の合計は最大 20,000 文字です。超過した場合は範囲や内容を減らしてください。自動では切り捨てません。統計には総メッセージ数、使用件数、文字数、選択した上限、省略件数を表示します。取引内容のチェックは、省略したメッセージ・過去の会話・背景説明を含む入力全体に適用されます。
- **過去の会話と背景説明**：過去の会話には `我：` / `对方：` と `me:` / `other:` が使えます。背景説明はチャットメッセージとして扱いません。補足はメモリ内だけに保持し、手動で消去できます。連携先のウィンドウ変更時やアプリ終了時にも消去します。同じウィンドウ内で相手を切り替えても自動検出できないため、別の会話に移る前に手動で消去してください。
- **ウィンドウに追従**：新規インストールでは既定でウィンドウ追従を使用します。既存の固定領域は再選択しても固定モードを維持します。追従を有効にするには、先に「ウィンドウに追従」を選んでから範囲を再選択してください。追従モードではウィンドウ移動に合わせて範囲も移動します。異なる DPI の画面間では、ウィンドウの幾何情報が整合している場合のみ追従します。サイズが 2 DIP を超えて変わった場合は再選択が必要です。対象ウィンドウを閉じた後やアプリ再起動後は、候補ウィンドウを確認してから連携を再開します。
- **必要時のみ取得**：分析ボタンを押した時に表示中の範囲を OCR します。常時バックグラウンド OCR や、最小化・遮蔽されたウィンドウのバックグラウンド取得は行いません。先にウィンドウを復元し、会話領域を表示してください。

## v1.3.0 の公開済み機能（当時の動作）

- **会話テキストの貼り付け**：範囲選択なしで分析できます。`我：` / `对方：` と `me:` / `other:` のプレフィックスに対応し、英語は大文字・小文字を区別せず、半角・全角のコロンを使用できます。入力は最大 20,000 文字で、分析対象は最後の 10 メッセージですが、取引内容の安全チェックは入力全体に適用されます。
- **キャンセルと完了済み段階からの再試行**：完了した判定と候補を保持し、最初の未完了段階から再開できます。ランク付けが失敗しても候補はコピーできます。再試行では、関係性の説明・モデル・返信設定を含む、元のタスク開始時に固定された設定を使用します。変更した設定を適用するには新しく分析してください。キャンセルすると後続の処理を停止し、古い結果を無視しますが、実行中の HTTP リクエストは完了またはタイムアウトまで続く場合があります。
- **返信設定**：長さ・口調・返信言語の共通設定を保存でき、ホーム画面でセッション中だけ一時的に上書きできます。返信言語は表示言語とは別に、簡体字中国語・英語・フランス語・ロシア語・日本語・韓国語の 6 言語、または「表示言語に従う」を選択できます。会話本文と各段階の結果はメモリ内に保持し、ローカルのチャット履歴には保存しません。

## 必要環境

- Windows 10/11（x64）
- Microsoft Edge WebView2 Runtime
- ソースから実行・ビルドする場合は Python 3.12、Node.js 20+、npm
- 初回利用時に TypeSafe / Jev API キーが必要。返信モデルの API キーは任意

## インストールと起動

リポジトリのルートで PowerShell を開きます:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1
powershell -ExecutionPolicy Bypass -File .\windows\start.ps1
```

初回利用時に、設定ページで Jev API キーを入力してください。候補返信を生成する場合は、返信モデルの設定・API キー・モデル名も追加します。

## 表示言語

簡体字中国語、英語、フランス語、ロシア語、日本語、韓国語に対応しています。設定ページで「表示言語」を選択すると、再起動なしで即座に保存・切り替わり、他の未保存の設定は送信されません。新規ユーザーは既定で Windows の表示言語に従い（未対応のシステム言語は英語にフォールバック）、既存ユーザーはアップグレード後も簡体字中国語を維持します。

多言語化はインターフェース、メッセージ、分析結果ラベルを対象としています。チャット本文とユーザーが入力した関係性の説明は翻訳されず、OCR も従来通りです。候補返信は独立した返信言語設定に従い、簡体字中国語・英語・フランス語・ロシア語・日本語・韓国語、または表示言語を使用します。

## 使い方

1. 支援したいチャットウィンドウを開き、通常のテキストチャットに入ります。
2. 「会話範囲を選択」をクリックし、チャットメッセージをドラッグで囲みます。
3. 「現在の選択範囲を分析」をクリックすると、Jev の判定と候補返信が表示されます。
4. 適切な候補を確認してコピーし、送信するかどうかはご自身で判断します。

本プログラムはチャットのデータベースを読み取らず、チャットの入力欄を操作せず、メッセージを自動送信することもありません。送金・紅包・決済などの取引内容は安全チェックでブロックされます。画像・音声・引用カードの内容は現時点で正確に復元できません。

## ビルド

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\build.ps1
```

ビルド成果物: `dist\Jev对话助手\Jev对话助手.exe`。PyInstaller が Vue アセット・OCR モデル・Python ランタイムをまとめてパッケージ化し、アップデート用ヘルパー `update_helper.exe` も生成します（本体の exe と同じ場所に同梱してください）。配布時は隣接する `_internal` フォルダを必ず一緒にしてください。対象 PC にも Microsoft Edge WebView2 Runtime が必要です。

## アプリ内アップデート

アプリは自らアップデートを取得できます。起動から数秒後に GitHub Releases を静かに確認し、新バージョンがあればホーム画面の上部にバナーを表示します。設定ページの「バージョンとアップデート」から手動で確認することもできます。確認時は `api.github.com` に最新バージョン番号を問い合わせるだけで、チャット内容が送信されることはありません。

アップデートを確定すると、アプリはバックグラウンドでリリースアーカイブをダウンロードし（進捗表示・キャンセル対応）、SHA256 を検証（リリースに `SHA256SUMS.txt` がある場合に有効。無い場合はサイズ検査にフォールバック）して一時フォルダに展開します。「再起動してインストール」をクリックするとメインプログラムが終了し、ヘルパー `update_helper.exe` がインストール先を差し替えて新バージョンを再起動します。途中で失敗した場合は旧バージョンへロールバックされます。設定やデータは `%APPDATA%` に保存されており、アップデートの影響を受けません。

## プライバシー

- OCR はローカルで実行されます。分析を実行すると、認識されたチャットテキストが TypeSafe Jev に送信されます。
- 返信モデルを有効にすると、会話テキストと Jev の判定が選択したモデルサービスに送信され、候補返信が生成されます。
- API キーは Windows 資格情報マネージャーに保存されます。`%APPDATA%\JevChatAssistant\settings.json` には秘密情報以外の設定のみ保存されます。
- モデル一覧の取得と接続テストでチャット内容が送信されることはありません。

設定や使用方法の詳細、制限事項については [`windows/README.md`](../windows/README.md) を参照してください。
