# v1.4.0 校对与回复调整

实现日期：2026-10-08。目标发布版本：v1.4.0。

## 用户流程

桌面采集或文本解析 → 修改正文、发言方和顺序 → 选择回复目的 → 确认分析 → 单条改写 → 按需撤销 → 手动排序 → 复制。

校对前没有分析服务调用；所有草稿、初始输入和改写历史只保留在内存。后端扫描原始输入、初始补充、校对内容和最终上下文，删改交易内容不能绕过检查。沿用全部／最后 10／20／50 条范围以及 20,000 字符预算。

回复目的包括通用、礼貌拒绝、澄清误会、结束话题和缓和冲突。确认时冻结模型、凭据、上下文、语言、风格和意图；失败重试沿用该任务参数。没有回复模型时仍能完成 Jev 判断。

候选支持更短、自然、委婉三种改写，以及连续改写的逐步撤销。改写或撤销立即清除全部旧评分，重新排序由用户触发。失败、取消和无效结果保留原内容，其他候选仍可复制。

## 桌面桥接

- `analyze` / `analyze_text`：获取校对草稿，返回任务标识；进度暴露 `review_id` 和 `review_messages`。
- `submit_review`：提交草稿标识、消息、上下文、偏好和目的，后端保留的原文不由前端覆盖。
- `discard_review`：销毁当前草稿及原始输入。
- `rewrite_reply` / `undo_reply` / `rank_replies`：传入任务标识和候选修订版本；改写及撤销另外指定候选序号。
- `retry_analysis`：保留原有分阶段重试，新增 `rewrite` 阶段。

进度新增任务目的、候选修订版本、每条候选可撤销次数与排序有效状态。旧配置无迁移，回复目的不落盘。三种模型协议和六种界面语言沿用现有实现。

## 首页模块显示

设置中的“首页模块显示”允许独立隐藏介绍、首页模型选择卡、识别消息和 Jev 判断展示，默认全部显示。开关立即保存到非机密配置，可一键恢复；不保存其他未提交设置，不读取或修改凭据，不改变运行中的分析任务。

输入、框选、校对、分析状态和回复操作保持显示；后台仍完成判断、生成及排序。模型选择卡隐藏后，可在设置选择模型。剩余模块自动占满可用列，全部隐藏结果展示时移除空容器。

新增 `set_module_visibility` 桥接及 `module_visibility` 设置字段，后端只允许四个展示模块，拒绝核心模块和非布尔值。旧配置默认全部显示，保存失败回滚。

本次增量验证：521 项 Python 测试通过，前端构建、模块开关浏览器冒烟及实际 EXE 保存／恢复／核心模块保护验证通过。新增浏览器冒烟已加入 CI。
